KEY TECHNICAL DECISIONS / LEARNINGS
- Kokoro is 24 kHz native. That is the fidelity ceiling; bitrate above 128k AAC is wasted. 48 kHz upsampling is cosmetic.
- Pauses: each paragraph is synthesised separately, joined with silence. PARA_GAP 0.5s between paragraphs, CHAP_GAP 1.4s between sections. Concat-gapless was the original "no pauses" bug.
- Mastering chain is what makes spoken word pleasant (the LibriVox-fatigue fix): highpass=f=70, deesser=i=0.4, loudnorm=I=-19:TP=-2:LRA=7. Output 44.1 kHz, 128k AAC.
- M4B MUST be muxed with -movflags +faststart or iOS Books silently refuses to import it.
- iCloud does NOT sync sideloaded (non-store) audiobooks - never has, by design. Manual import only: AirDrop -> Files -> Share -> Copy to Books, or Finder cable sync to the Audiobooks tab. EPUBs/PDFs sync, audiobooks do not.
- flow_preprocess semicolon rule is context-aware: ";" before a conjunction (and/but/or...) -> ",", otherwise -> ". " + capitalise. Optional --split-long N splits monster sentences but alters Tolstoy's cadence (use sparingly).
